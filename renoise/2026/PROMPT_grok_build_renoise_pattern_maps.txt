## 2) Qué hace el tool

El tool aplica **mapas de patrones**: listas ordenadas de índices de patrón que **reemplazan por completo** la Pattern Sequence de la canción actual.

Al aplicar un mapa:
1. Calcula el patrón UI máximo necesario.
2. Crea patrones vacíos en el pool si faltan.
3. Asigna `sequencer.pattern_sequence` con la secuencia del mapa.
4. 
5. Pone el cursor de sequence en el slot 1.
6. **NO abre** el Pattern Matrix. Debe quedar **cerrado siempre**:
   - al inicio de apply: `renoise.app().window.pattern_matrix_is_visible = false`
   - al final de apply: otra vez `false`
7. Muestra status en la barra de Renoise y un `print` en la terminal de scripting.
8. Usa `song:describe_undo(...)` para un undo limpio.

### Reglas de parseo (OBLIGATORIAS)

1. Un mapa empieza en una línea: `=== TITULO ===` (espacios opcionales alrededor del título).
2. Debajo van **solo números de patrón**, uno por línea (enteros ≥ 0).
3. Los números son los de la **UI de Renoise** (0-based: `0` = patrón 00, `7` = patrón 07).
4. **Ignora** cualquier otra cosa: comentarios, letras, nombres de canciones, texto suelto, líneas vacías, espacios extra al final de la línea.
5. Extrae de cada línea el **primer entero** si hay ruido; si la línea no tiene número, sáltala.
6. El **título del mapa** es el texto entre `===` y `===` (trim). Ese título es el que aparece en el menú **sin comillas y sin prefijo** tipo "Apply map".
7. Puede haber N mapas en un solo archivo. Implementa **todos**.
8. Orden del menú = orden de aparición en el archivo.

## 4) Índices UI vs API (crítico — no fallar aquí)

| Concepto | Valor |
|----------|--------|
| Número en el archivo / menú UI | 0-based (`0`, `1`, `13`…) |
| `song.patterns[i]` / `pattern_sequence` | **1-based** (`ui + 1`) |

Helpers obligatorios:

```lua
local function ui_to_api(ui_pattern)
  return ui_pattern + 1
end
```

Al construir la sequence:

```lua
table.insert(new_sequence, ui_to_api(entry.pattern))
```

## 5) Crear patrones si no existen (API correcta)

**PROHIBIDO:** `song.patterns:insert()` → no existe y crashea.

**CORRECTO:**

```lua
while #song.patterns < needed do
  song.sequencer:insert_new_pattern_at(#song.sequencer.pattern_sequence + 1)
end
```

donde `needed = max_ui_pattern + 1`.

## 6) Estructura de código (mantén esta arquitectura)

Archivos:
- `manifest.xml`
- `main.lua`
- empaquetar `.xrnx`

En `main.lua`:

1. Constantes: `TOOL_NAME`, `TOOL_VERSION`, `MENU_FOLDER` (= TOOL_NAME)
2. `ui_to_api`, `numbers_to_map(numbers)`
   `numbers_to_map` convierte `{0,1,2}` → `{{pattern=0},{pattern=1},{pattern=2}}`
3. `ensure_patterns_exist(max_ui)`
4. `set_pattern_name(ui, name)` vía `song:pattern(ui_to_api(ui)).name`
5. `set_pattern_color(ui, {r,g,b})` en **todos** los tracks:

```lua
song:pattern(api):track(t).color = {r, g, b}  -- tabla NUEVA cada vez
```

   Color opcional de referencia: verde `#AEF504` = `{0xAE, 0xF5, 0x04}`

6. Definición de cada mapa:
   - Por defecto solo números: `local MAP_X = numbers_to_map { 0, 1, 2, ... }`
   - Si hay anotaciones especiales en el archivo tipo `7 - terror` o instrucciones del usuario, soporta:

```lua
{pattern = 7, label = "terror", color = true}
```

7. Registro central:

```lua
local MAPS = {
  {id = "...", title = "titulo_menu", map = MAP_...},
  ...
}
```

8. `apply_map(map, map_name)` con la lógica de la sección 2
9. `register_map_actions` para **cada** mapa:
   - Menús (solo el título, sin "Apply map", sin comillas):
     - `Main Menu:Tools:MENU_FOLDER:TITLE`
     - `Pattern Sequencer:MENU_FOLDER:TITLE`
     - `Pattern Matrix:MENU_FOLDER:TITLE`
   - Keybinding (**exactamente 2 dos-puntos** en todo el string):

```lua
"Global:Tools:" .. TOOL_NAME .. " - " .. title
```

     Forma válida: `scope:topic:name`
     **Inválido:** `Global:Tools:Foo: Bar` (tercer `:`)

## 7) Errores de API que NO debes repetir

| Error | Causa | Solución |
|-------|--------|----------|
| `attempt to call method 'insert' (a nil value)` | `song.patterns:insert()` | `sequencer:insert_new_pattern_at` |
| `invalid key binding entry... doubled colons` | keybinding con más de 2 `:` | `Global:Tools:Name - map` |
| `Expected a 'Id' field value in the form 'abc.def.ghi'` | Id sin 3 partes | `com.autor.herramienta` |
| Pattern Matrix se abre sola | forzar visible / no cerrar | `pattern_matrix_is_visible = false` al inicio y final |
| Colores no se ven / sequence mal | índices 0 vs 1 | siempre `ui + 1` en API |
